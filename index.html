常见问题

如何在其他 App 里划词直接查？
打开 iPhone「设置 › App › 默认 App › 翻译」，选择「和辞」。之后在任何 App 选中日语文字，点菜单中的「翻译」即可弹出词典。
需要联网吗？
不需要。词典、语法、例句、电子书阅读和手写识别全部内置，离线可用。只有当你在「设置 › AI 服务」或「发音设置」里自行填入某家服务商的 API Key 并使用对应功能时，相关的日语文本才会发送给那家服务商。
中文释义从哪里来？
大部分来自中文维基词典的日语词条；没有收录的词由 iOS 内置离线翻译生成，并标有「机翻」。
AI 功能怎么用？要另外付费吗？
AI 是可选功能，默认关闭。在「设置 › AI 服务」选择服务商（Claude、OpenAI、Gemini、DeepSeek、通义千问等，或任何兼容 OpenAI 接口的地址），填入你自己的 API Key 即可。费用由服务商按用量向你收取，本 App 不另收费，也不经手你的请求。
可以导入哪些电子书？
没有 DRM 的 EPUB 和 TXT（含青空文庫格式）。Kindle、Apple Books、Kobo 等商店购买的加密书无法导入。
我的词库能备份吗？
在「设置 › 我的词库」可以导出为 .jpdict 文件，用 AirDrop 或聊天软件发给他人或自己保存，打开文件即可导入。

FAQ

How do I look up words from other apps?
Go to iPhone Settings › Apps › Default Apps › Translation and choose 和辞. Then select Japanese text in any app and tap Translate.
Does it need an internet connection?
No. The dictionary, grammar library, examples, e-book reader and handwriting recognition are all built in. Text is only sent to a third party if you enter your own API key for an AI or speech provider in Settings and use that feature.
